# Тимлид — практический курс

Статический русскоязычный учебный сайт для перехода от индивидуальной разработки к руководству инженерной командой. Основной маршрут содержит **12 направлений и 36 уроков**: роль и ответственность, продукт, планирование, инженерное качество, эксплуатация, развитие людей, найм, коммуникация, решения и делегирование, метрики, организация и личная зрелость лидера. В конце — сквозная итоговая работа на 90 дней и критерии её проверки.

Каждый урок включает объяснение, алгоритм действий, рабочий пример, задание, критерии готовности, типичные ошибки и вопросы для самопроверки. Черновик задания и отметка о прохождении сохраняются в `localStorage` текущего браузера. Это средство самостоятельной практики, а не автоматическая сертификация.

## Запуск

Откройте `index.html` в браузере. Для локального HTTP-просмотра запустите из корня проекта:

```text
python -m http.server 8000
```

Затем откройте `http://localhost:8000/`. Сборка и внешние JavaScript-зависимости не нужны. Шрифты при наличии сети загружаются из Google Fonts; локальные системные шрифты служат запасным вариантом.

## Архив архитектора

Курс по архитектуре ПО сохранён на странице [`archive/index.html`](archive/index.html). В основной навигации и в верхней панели есть ссылка на архив; внутри архива есть обратная ссылка на курс тимлида. Архив использует прежние `data.js`, `detailed.js`, `term-examples.js`, `lesson-view.js`, `glossary-view.js`, `app.js` и `styles.css`. Его существующие отметки о прохождении остаются в отдельном ключе браузера.

## Структура

- `index.html`, `teamlead.css`, `teamlead-app.js` — основной курс и интерфейс.
- `teamlead-data.js` — направления, полный текст уроков и шаблоны.
- `archive/index.html` — прежний курс архитектора.
- `source/initial-outline.txt` — исходная памятка для архивного курса.

Сайт использует относительные пути и может размещаться на GitHub Pages в корне репозитория или подпапке проекта. Для публикации загрузите весь каталог, включая `archive/` и прежние файлы архивного курса. В настройках Pages выберите публикацию из ветки и корневой папки.
