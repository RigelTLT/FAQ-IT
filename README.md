# Тимлид — практический курс

Статический русскоязычный учебный сайт. Доступны три самостоятельные программы:

- [Python, BI, AI и интеграции с 1С](data-ai/index.html) — 12 этапов, 48 уроков, 12 практикумов, сквозной проект и расписание на 2 ноября — 31 декабря 2026.
- Основной маршрут тимлида — 12 направлений и 36 уроков: роль, продукт, планирование, инженерное качество, эксплуатация, люди, найм, коммуникация, решения, метрики, организация и личная зрелость. Итоговая работа — план на 90 дней.
- [Архив архитектора](archive/index.html) — сохранённая предыдущая программа.

Каждый урок включает объяснение, алгоритм действий, рабочий пример, задание, критерии готовности, типичные ошибки и вопросы для самопроверки. Черновик задания и отметка о прохождении сохраняются в `localStorage` текущего браузера. Это средство самостоятельной практики, а не автоматическая сертификация.

## Запуск

Откройте `index.html` в браузере. Для локального HTTP-просмотра запустите из корня проекта:

```text
python -m http.server 8000
```

Затем откройте `http://localhost:8000/`. Сборка и внешние JavaScript-зависимости не нужны. Шрифты при наличии сети загружаются из Google Fonts; локальные системные шрифты служат запасным вариантом.

## Python, BI, AI и 1С

Новый курс открывается по адресу `http://localhost:8000/data-ai/index.html` или через заметную ссылку на главной странице. Сам сайт также работает при открытии HTML-файла: тексты загружаются обычными script, без fetch и серверной сборки. Сохранение в браузере зависит от его политики; экспортируйте JSON-копию перед сменой браузера/адреса сайта.

Темы: инженерный Python и ревью, pandas/Polars/SQLAlchemy, экспертный SQL, DWH/звезда/снежинка/SCD2, УТ/УНФ/Бухгалтерия и исследование неизвестной АТК, файлы/OData/HTTP/шина, ETL/ELT/Prefect/Airflow, FastAPI/Django, Power BI/Qlik/Superset/Metabase, scikit-learn, PyTorch/TensorFlow, векторные БД, LangChain/LlamaIndex и оценка RAG.

Каждый урок содержит 3–4 объяснения, пример кода с разбором, четыре самостоятельных задания, ориентир решения, критерии, типичные ошибки, вопросы с раскрываемыми ответами и официальные источники. Примеры отмечены как самостоятельные либо как фрагменты с дополнительными условиями. Код не выполняется на сайте: запускайте его в отдельных учебных окружениях.

[Редактируемый Excel-план](outputs/python-bi-ai-1c-2026/learning-plan.xlsx) содержит 60 дней и 372 часа: 44 будних дня по 7 часов (середина запрошенного диапазона 6–8), 16 выходных по условным 4 часа. Настройки и ручные часы каждого дня можно менять. Четыре листа: «Расписание», «Этапы», «Уроки», «Справочник». Даты являются числовыми Excel-датами, часы и прогресс рассчитываются формулами; статусы выбираются из списка. Адреса уроков в книге предполагают сервер на порту 8000 и копируются в браузер.

Прогресс, заметки, состояния практикумов и настройки расписания сайта хранятся в ключе `data-ai-course-v1`. На странице «Справочник» есть экспорт и импорт JSON. Курс тимлида и архив используют прежние отдельные ключи. **Excel и браузер не синхронизируются**: изменения каждого сохраняются только в нём.

Стартовый [лабораторный комплект](data-ai/lab/README.md) включает синтетические данные, read-only mock HTTP feed, рабочее SQLite-ядро с версиями/inbox/rollback, тесты и PostgreSQL DDL. Реальная 1С, полный OData, BI, модели и альтернативные среды развиваются по заданиям. Точное значение АТК неизвестно; в курсе предусмотрено исследование, без выдуманной схемы.

Подготовка интенсивная и предполагает основы Python/SQL/Git. Прохождение страниц само по себе не подтверждает экспертный уровень: готовность проверяется практикумами, восстановлением после сбоя и защитой проекта.

## Архив архитектора

Курс по архитектуре ПО сохранён на странице [`archive/index.html`](archive/index.html). В основной навигации и в верхней панели есть ссылка на архив; внутри архива есть обратная ссылка на курс тимлида. Архив использует прежние `data.js`, `detailed.js`, `term-examples.js`, `lesson-view.js`, `glossary-view.js`, `app.js` и `styles.css`. Его существующие отметки о прохождении остаются в отдельном ключе браузера.

## Структура

- `index.html`, `teamlead.css`, `teamlead-app.js` — основной курс и интерфейс.
- `teamlead-data.js` — направления, полный текст уроков и шаблоны.
- `archive/index.html` — прежний курс архитектора.
- `source/initial-outline.txt` — исходная памятка для архивного курса.
- `data-ai/index.html`, `course-app.js`, `course.css` — интерфейс новой программы.
- `data-ai/course-data.js`, `lessons/*.js`, `schedule.js` — программа, 48 уроков и общий 60-дневный маршрут.
- `data-ai/lab/` — запускаемая учебная лаборатория и синтетические примеры.
- `outputs/python-bi-ai-1c-2026/learning-plan.xlsx` — редактируемое расписание.

Сайт использует относительные пути и может размещаться на GitHub Pages в корне репозитория или подпапке проекта. Для публикации загрузите весь каталог, включая `data-ai/`, Excel из `outputs/`, `archive/` и прежние файлы архивного курса. В настройках Pages выберите публикацию из ветки и корневой папки. Публикация не выполнялась автоматически.
