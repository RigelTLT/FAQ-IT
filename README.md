# Архитектура ПО — открытый справочник

Статический русскоязычный сайт для последовательного изучения программной архитектуры с нуля. Основа содержания — предоставленная пользователем памятка из 20 разделов. Материал дополнен подробными объяснениями, примерами, практическими заданиями и вопросами для самопроверки по каждой теме. У каждого термина словаря есть определение, пример из практики и короткий фрагмент кода или помеченного псевдокода.

## Запуск

Откройте `index.html` в браузере. Сборка и зависимости не нужны. Для локального HTTP-просмотра можно запустить `python -m http.server 8000` и открыть `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создайте репозиторий GitHub и загрузите в его корень все файлы проекта, включая `index.html`, `styles.css`, `app.js`, `data.js`, `detailed.js`, `term-examples.js`, `lesson-view.js`, `glossary-view.js` и `README.md`.
2. В настройках репозитория откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**, затем ветку `main` и папку `/ (root)`.
4. Сохраните настройку. Адрес сайта появится в разделе Pages после публикации.

Сайт использует относительные пути, поэтому работает и в репозитории вида `username.github.io/project-name`. Отметки о прохождении хранятся только в `localStorage` браузера и не синхронизируются между устройствами.

## Как дополнять

В `data.js` находятся этапы, краткие карточки уроков и словарь. У каждого урока есть `terms` — идентификаторы понятий, которые раскрываются прямо на странице урока. Примеры терминов хранятся в `term-examples.js` под теми же идентификаторами. Полная карточка словаря доступна по ссылке под определением. Подробный текст урока находится в `detailed.js` под тем же идентификатором. Отображение страниц задают `lesson-view.js` и `glossary-view.js`. Новые термины добавляются и в `glossary`, и в `termExamples`; новые уроки — в `lessons` и `lessonDetails`. Сайт не использует внешние библиотеки.

Исходная памятка сохранена в `source/initial-outline.txt` для сверки и дальнейшего расширения.
